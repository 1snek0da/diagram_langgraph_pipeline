# Demo 交互选择设计

## 目标

将 `demo` 从固定运行 `full` 任务调整为可交互选择任务：用户启动 Demo 后使用上下方向键移动选项，按 Enter 确认，再运行对应的离线 Router 线路。

## 交互范围

菜单提供五个选项，并保持 Router 中的任务顺序：

1. full
2. industry
3. fundamental
4. technical
5. market

默认高亮 `full`。菜单显示当前选中项，方向键循环移动，Enter 确认；不需要输入数据库连接、股票代码或 LLM 配置。

## 运行行为

- Demo 继续使用现有固定的 DEMO、BENCH、SECTOR 离线数据。
- 确认任务后，将 `task_type` 写入 Demo 初始状态并调用现有 `run_research`。
- Router 负责启用和屏蔽节点，报告按所选任务生成。
- 非交互环境或不支持方向键时，显示清晰错误并提示使用测试或真实 `run` 命令；不改变真实 CLI 入口。

## 验证

- 为菜单选择逻辑增加单元测试，覆盖上下移动、循环和 Enter 确认。
- 为五个任务增加 Demo 运行测试，确认所选任务传入状态且屏蔽节点保持生效。
- 运行完整测试套件，并在终端实际执行一次交互 Demo。
